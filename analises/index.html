04 · O que ninguém te explicou

Quatro mitos sobre análise normal.

As análises convencionais foram desenhadas para detectar doença instalada. Quando as lês sob a lente funcional, o quadro é completamente diferente. Quatro coisas que mudam a forma de olhar para os teus dados.

  1. Normal não significa óptimo.

    Os intervalos de referência são estatística populacional — onde caem 95% das pessoas testadas. Isto não significa que esses 95% estão saudáveis. Significa apenas que é onde se distribuem. Óptimo para ti é uma janela mais estreita, calibrada para função, não para detecção de doença.

  2. Os intervalos foram desenhados para detectar doença — não para optimizar função.

    A ferritina em 15 ng/mL é "normal" no laboratório porque acima desse valor não há anemia franca. Mas a literatura funcional associa ferritina abaixo de 60 a fadiga, queda de cabelo, e oxigenação tecidual subóptima. Não é doença. É função abaixo do que poderia ser.

  3. Um valor isolado é uma fotografia. A trajectória conta mais.

    Uma análise mostra o agora. Mas o teu corpo conta a história ao longo do tempo. A ferritina a descer de 80 para 50 é mais preocupante do que estar estável em 45. A primeira é movimento. A segunda é equilíbrio. Os intervalos não te dizem isso.

  4. Os teus sintomas são dados clínicos. Tão clínicos quanto os números.

    Análises todas normais com sintomas reais não é "psicológico". É a indicação de que se pediu a pergunta errada. A medicina convencional pergunta "há doença?". A medicina funcional pergunta "há função óptima?". São perguntas diferentes — geram respostas diferentes.

O que estes valores dizem juntos

15 · Antes de avançares

O que costumam perguntar.

E se as minhas análises estiverem todas óptimas?

Também é uma resposta. E é a resposta mais valiosa que podes ter neste momento — porque te liberta de procurar a causa nas análises e abre espaço para olhar para sono, stress, padrão alimentar, ciclo. Faço-te essa devolução com a mesma seriedade.

Posso enviar análises antigas?

Aceito análises feitas até há 6 meses. Mais antigas perdem fiabilidade clínica — o corpo muda. Se for mesmo importante, podemos discutir, mas a recomendação é repetir.

Quais análises preciso de ter?

Idealmente um painel funcional alargado — hemograma, perfil metabólico, tiróide completa, vitaminas, ferro, hormonas (consoante a fase). Se não souberes, na avaliação prévia gratuita ajudo-te a perceber se o que tens chega.

Sou clínica funcional, não médica. Não diagnostico, não prescrevo, não substituo.
